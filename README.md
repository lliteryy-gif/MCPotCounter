# Potion Counter — Fabric 1.21.11

Клиентский счётчик взрывных зелий «Исцеление II» возле обычного ника:
`Player [Поты: 12]` либо `[Поты: 12] Player`.

## Статус
Исходники подготовлены по API 1.21.11. Компиляция и запуск Minecraft в среде автора
не выполнены: недоступна загрузка зависимостей, установлен только Java 17.
Это проект для сборки и проверки, НЕ уже проверенный игровой релиз.

## Что считает
- Только Item = SPLASH_POTION, PotionContents = STRONG_HEALING.
- Обычные питьевые, туманные зелья, Исцеление I и другие эффекты не учитываются.
- Считает бросок, даже если зелье никого не вылечило. Не считает число вылеченных игроков.
- Владелец определяется через владельца снаряда, не по ближайшему игроку.
- Повторные пакеты одного снаряда не увеличивают счётчик.
- Сброс не позволяет уже летящему учтённому зелью засчитаться повторно.
- Счётчики хранятся по UUID в пределах подключения; смерть не сбрасывает счётчик.
- При выходе/переподключении счётчики очищаются. Сторона и видимость сохраняются.

## Команды (локальные, не требуют OP)
| Команда | Действие |
| --- | --- |
| `/potcounter reset Ник` | Сбросить конкретного игрока; есть подсказки ников |
| `/potcounter resetall` | Сбросить всех |
| `/potcounter side left` | Слева от ника |
| `/potcounter side right` | Справа от ника |
| `/potcounter count Ник` | Посмотреть число в чате, в том числе своё |
| `/potcounter hide` | Скрыть подписи, подсчёт продолжается |
| `/potcounter show` | Вернуть подписи |

## Ограничения
Мод видит только снаряды, которые сервер отправляет клиенту. Не восстанавливает
броски до подключения и за пределами серверной дальности отслеживания.
Снаряд, впервые попавший в дальность наблюдения уже в полёте, может быть учтён как
наблюдаемый бросок. На сервере, скрывающем владельца или состав зелья,
соответствующий бросок пропускается: угадывания по цвету/анимации нет.
Невидимые/скрытые ванилью ники мод не показывает; свой ник ваниль обычно не рисует,
свой счётчик доступен через команду. Моды, полностью заменяющие name tags, могут
потребовать отдельной интеграции. Сторона выбирается для всех подписей сразу.
Переименованные стандартные зелья учитываются по составу, а не по названию.
Нестандартные зелья серверных плагинов могут не соответствовать STRONG_HEALING.

## Проверка в игре после сборки
1. На отдельном тестовом мире/сервере два игрока. Сначала проверить, что нет mixin-ошибок.
2. Игрок A бросает 3 взрывных Healing II: у A +3, у B +0; бросок себе под ноги тоже +1.
3. Healing I, Poison, питьевое и lingering Healing II: счётчик не меняется.
4. A и B бросают одновременно: каждый получает свой +1.
5. Бросить Healing II вверх и сбросить A, пока оно летит: после приземления остаётся 0.
6. Проверить обе стороны подписи, resetall, hide/show и повторный вход (счётчики 0).
